# GAME TEBAK KATA
### Think. Guess. Discover.

Game Tebak Kata is an interactive word guessing game developed using HTML, CSS, and JavaScript.

The game challenges players to guess hidden words through an engaging and interactive experience.

## Features

- **Interactive Gameplay** — Play an engaging word guessing game.
- **Word Challenges** — Test your vocabulary and guessing skills.
- **Simple Interface** — Enjoy a clean and easy-to-use design.

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

```text
game-tebak-kata/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Getting Started

1. Clone this repository.
2. Open the project folder.
3. Run `index.html` in your browser.
